## 三、核心模型：类、对象、方法、属性

这是整个面向对象编程的**全部地基**。用汽车打比方：

| 概念 | 含义 | 汽车类比 |
|---|---|---|
| **类（class）** | 一张**图纸**，描述了"这类东西长什么样、会做什么" | 汽车的设计图 |
| **对象（实例）** | 按图纸**造出来的具体东西** | 你车库里的那辆车 |
| **方法（method）** | 这个对象**会做的事** → **调用时要写括号** | `car.start()`、`car.brake()` |
| **属性（attribute）** | 这个对象**有的东西** → **写的时候不写括号** | `car.color`、`car.speed` |

### 最重要的一条规律（背下来）

> **`.` 后面带括号 `()` 的是方法（动作）；不带括号的是属性（数据）。**

```python
car.start()      # 有括号 → 方法，"启动"这个动作
car.color        # 没括号 → 属性，"颜色"这个数据
```

**不确定一个陌生的东西是什么，就先看有没有括号。** 这一条能解决你 80% 的困惑。

## 四、回到你的代码，逐行翻译

```python
import sqlite3

conn = sqlite3.connect("students.db")
cur = conn.cursor()
cur.execute("SELECT * FROM students")
rows = cur.fetchall()
```

**逐句拆开：**

| 代码片段 | 它是什么 | 说明 |
|---|---|---|
| `sqlite3` | **模块** | 一个 Python 文件（库），`import` 进来的 |
| `sqlite3.connect` | **函数** | 模块里的一个函数。给它文件名，**它返回一个 Connection 对象** |
| `conn` | **变量** | 你起的名字，装的就是那个 Connection 对象 |
| `conn.cursor` | **方法** | Connection 对象"**会做的事**"之一：创建一个游标 |
| `conn.cursor()` | **调用**这个方法，**它返回一个 Cursor 对象** | |
| `cur` | **变量** | 装的是那个 Cursor 对象 |
| `cur.execute` | **方法** | Cursor 对象的动作：执行一句 SQL |
| `cur.fetchall` | **方法** | Cursor 对象的动作：把所有结果取回来 |
| `rows` | **变量** | 装的是查询结果（一个列表） |

**一句话总结这几行的流程**：

> 连接数据库 → 从连接上开一个游标 → 用游标执行 SQL → 用游标取回结果

**为什么要经过游标，不能直接 `conn.execute()`？**
因为一个连接上可能同时有多个操作序列在进行，游标用来追踪"我执行到哪了"。**你现在不用深究，知道它是个"执行 SQL 的工具"就够了。**

## 五、把之前学过的代码也翻译一遍

回头看，你其实**早就在用对象了**，只是没意识到：

### 5.1 `app = FastAPI()`

```python
app = FastAPI()
```

| 部分 | 是什么 |
|---|---|
| `FastAPI` | **类**（图纸） |
| `FastAPI()` | **调用类**，造出一个实例（对象） |
| `app` | 变量，装着这个对象 |

> 💡 `类名()` 带括号 = "按这张图纸造一个出来"。

### 5.2 `req.name`

```python
@app.post("/profile")
def create_profile(req: ProfileRequest):
    return {"student": req.name}
```

- `req` 是一个 `ProfileRequest` **对象**
- `req.name` **不带括号** → 是**属性** → 取出它身上的 `name` 数据

### 5.3 你自己定义过类！

```python
class ProfileRequest(BaseModel):
    name: str
    major: str
```

**记得这段吗？你早就写过"类"了！**

`class ProfileRequest` 就是在**画一张图纸**——它规定了"一个画像请求长什么样：有 name、有 major、有 age、有 goal"。

每次有请求进来，FastAPI 就**按这张图纸造一个对象**，然后传给你的函数。所以函数里才可以用 `req.name`。

> **这就是为什么我一直说 Pydantic 那部分是"地基"——它不只是校验，它是"用类描述数据结构"这套思路的开始。**

### 5.4 `conn.commit()`

- `conn` 是 Connection 对象
- `commit` 是它的**方法**（有括号）→ 动作

## 六、杀手锏：用 Python 问 Python

这是**最重要的一节**。以后遇到任何看不懂的东西，用这三条命令，**不用问我**。

新建一个 `backend/what_is_this.py`，跑一下：

```python
import sqlite3

conn = sqlite3.connect(":memory:")     # ":memory:" = 内存数据库，不落盘，适合做实验

print(type(conn))                       # 这东西是什么类？
print(type(conn.cursor()))              # 游标是什么类？

print([x for x in dir(conn) if not x.startswith("_")])   # 它有哪些能力？
```

### 三个函数，各有用途

| 函数 | 用途 | 例子 |
|---|---|---|
| `type(东西)` | **它是什么类** | `<class 'sqlite3.Connection'>` |
| `dir(东西)` | **它有哪些属性和方法** | `['close', 'commit', 'cursor', 'execute', ...]` |
| `help(东西)` | **看官方说明** | `help(conn.cursor)` |

> `dir()` 的结果里，**下划线开头的先全部忽略**（那是内部用的），剩下的就是它对你开放的能力。

### VS Code 里更快的办法

**把鼠标悬停在变量上**，VS Code 会告诉你它的类型。这个最快，日常就用这个。

## 七、读陌生代码的三步法

**以后遇到看不懂的代码，照这个顺序走：**

### 第 1 步：看整体结构

这行是**赋值**？**调用**？**返回**？

```python
conn = sqlite3.connect("students.db")
#  ↑赋值     ↑调用
```

→ 先确定"这一行在干什么事"，别急着抠细节。

### 第 2 步：用 `type()` 问出每个东西是什么

```python
print(type(conn))    # 哦，是个 Connection 对象
```

→ 从"未知"变成"已知类"，你的脑子立刻就有抓手了。

### 第 3 步：区分 `.xxx()` 和 `.xxx`

- 有括号 → 方法 → 它在**做事**，可能返回新东西
- 无括号 → 属性 → 它在**给数据**

### 第 4 步（可选）：查文档

不确定的时候，用 `help()` 或直接搜索"python sqlite3 cursor execute"，看官方文档。**官方文档是最权威的，别只看博客。**

## 附录：SQL 关键字要大写还是小写？

**你的问题**：写 SQL 时是不是都小写更好？

**答案**：**SQL 关键字大小写不敏感**——`CREATE TABLE`、`create table`、`Create Table` 效果完全一样。

但**行业惯例是关键字大写**：

```sql
SELECT name, age FROM students WHERE age > 20     -- ✅ 常见
select name, age from students where age > 20     -- ⚠️ 能跑，但少见
```

**为什么大写更好**：一眼就能区分"SQL 关键字"和"表名 / 列名"。

```sql
SELECT name FROM students     -- SELECT/FROM 是关键字，大写；name/students 是名字，小写
```

整句一个大小写，你的眼睛得先"解析"才知道哪个是哪个。

> 📌 简单说：**关键字大写，你自己的表名列名小写**。这样扫一眼就分得清。
